    Besoins de capacité détectés
    
                
    Les besoins sont générés automatiquement quand un débat ou un outil signale une capacité manquante. Ils restent en attente jusqu'à approbation humaine.
    
                
    Chargement…
    
            
    

            
            
    
                
    Skills
    
                
    Les skills sont des modules réutilisables. Un skill doit être approuvé puis activé avant d'être utilisable.
    
                
    Chargement…
    
            
    

            
            
    
                
    Tools
    
                
    Les tools sont des outils générés dans un bac à sable. Le code n'est jamais exécuté dans l'environnement principal avant approbation.
    
                
    Chargement…
    
            
    

            
            
    
                
    Pipeline d'approbation
    
                
    Chaque skill ou tool proposé passe par un pipeline obligatoire : Détection → Spécification → Génération → Audit sécurité → Tests bac à sable → Approbation humaine → Activation.
    
                
    Chargement…
    
            
    
        
    
    
    

    

    
    
    
        
    Sandbox expérimental (couche optionnelle).
        Jouer avec un exécuteur isolé, sans que le core stable n'en dépende. Ici vous décrivez/choisissez,
        le labo s'occupe de l'infra. Rien n'est branché — si un exécuteur prouve sa valeur, il pourra être
        promu au core. Les exécuteurs not-connected sont honnêtement refusés.
    

        
    
            
            
    
                
    Vision & exécuteurs
    
                
    Laboratoire expérimental modulaire pour l'étude
                scientifique des systèmes de débat / génération multi-agents. Le chercheur décrit
                l'expérience, le laboratoire s'occupe de l'infrastructure. C'est un banc d'essai :
                chaque exécuteur ci-dessous indique s'il est branché (connected) ou réservé
                (not-connected).
    
                
    Chargement…
    
                
    Un exécuteur
                not-connected (ex. hermes_debate, projet séparé) est listé mais ne
                peut pas tourner ici — aucun faux résultat n'est produit.
    
            
    
        
    

        
    
            
    Feedback temps réel 
    
            
    Timeline live des runs longs (llm_sweep) : chaque
            tour publié dès qu'il finit. La synthèse (observation / conclusion / pistes) apparaît en fin.
